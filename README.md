# Personal Profile Card

A modern, responsive personal profile card component built using semantic HTML5, modern CSS3 styling, and interactive JavaScript.

## 🚀 Features

- **Responsive Design**: Adapts cleanly across mobile, tablet, and desktop screens.
- **Interactive Follow Button**: Dynamic toggle between "Follow" and "Following" states using Vanilla JavaScript.
- **Social Media Links**: Quick access to GitHub, LinkedIn, and Instagram profiles.
- **Clean & Modern UI**: Centered card layout with avatar styling and subtle hover transitions.

## 🛠️ Built With

- **HTML5**: Semantic document structure
- **CSS3**: Modern layouts, flexbox, custom styling, and transition effects
- **JavaScript (ES6)**: DOM manipulation and state toggling

## 📁 Project Structure


## 💻 Getting Started

To run this project locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sutapa97382/personal-profile--card.git
   ```

2. **Navigate into the project directory**:
   ```bash
   cd personal-profile--card
   ```

3. **Open the project**:
   - Simply double-click `index.html` to open it in your browser, or
   - Use VS Code Live Server extension to preview.
